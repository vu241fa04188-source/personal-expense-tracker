# 💰 Personal Expense Tracker (MERN Stack)

Full-Stack Personal Expense Tracker Web Application built for B.Tech CLA-4 Project Evaluation.

---

## 🌟 Features
- **User Authentication:** Secure registration and login using JWT & salted bcrypt password hashing.
- **Dynamic Dashboard:** Real-time summary cards for Total Income, Total Expenses, and Remaining Balance.
- **Data Visualizations:** Interactive Monthly Cash Flow Bar Chart and Category-wise Spending Doughnut Chart (Chart.js).
- **CRUD Operations:** Add, Edit, Delete, and View income and expense transactions.
- **Multi-Filter & Search:** Real-time search by title, category filtering, transaction type filtering, and date range filtering.
- **Annual Reports:** 12-month performance breakdown with net savings calculations and savings rates.
- **Responsive Design:** Clean, mobile-friendly interface with sidebar navigation and quick action buttons.

---

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML5, CSS3, Chart.js, React-Chartjs-2, Lucide Icons, Axios
- **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), Bcryptjs, CORS, Dotenv
- **Database:** MongoDB (Atlas Cloud / Local MongoDB) with Mongoose ODM

---

## 🚀 How to Run Locally

### 1. Backend Setup
```bash
cd backend
npm install
# Create a .env file based on .env.example
npm run dev
```
*Backend runs on: `http://localhost:5000`*

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on: `http://localhost:3000`*
